🥽 VRC Nexus – Twitch-Panel einrichten

  1. Unten auf „Verbindungscode erzeugen“ klicken.
  2. In der Windows-App VRC Nexus: Stream-Bot → 📺 Leiste & Twitch-Panel → Code einfügen, „Panel mit Daten versorgen“ anhaken, speichern.
  3. Dort wählst du auch, was Zuschauer sehen (Welt, Puls, Song, Befehle, Belohnungen, Bestenliste, Umfrage, Ziel).

Status wird geprüft …

Ein neuer Code macht den alten ungültig. Der Code wird auf dem GhostNode-Server nur als Prüfsumme gespeichert. Das Panel zeigt nie 18+-Inhalte und keine Welt, solange der Privat-Modus an ist.
